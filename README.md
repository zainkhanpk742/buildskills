# BuildSkills.com.pk — Starter

A Next.js starter for the BuildSkills learning + services platform.

## Run locally

1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local address shown by Next.js.

## Next implementation steps

- Add the remaining page templates.
- Connect the content model/database.
- Add real question and guide content.
- Add search.
- Add portfolio projects.
- Add service landing pages.
- Add your email and Fiverr URL.
- Add analytics/Search Console after deployment.
- Replace placeholder copy with reviewed production content.

The starter intentionally keeps the homepage lightweight and server-rendered so the platform can grow without sacrificing performance or crawlability.
